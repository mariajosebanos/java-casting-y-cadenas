# Casting de tipos y manipulación de cadenas en Java

Ejercicios de introducción a Java que hacen uso de: operadores aritméticos, casting implícito y explícito entre tipos numéricos, 
entrada de datos con Scanner y manipulación de cadenas con métodos nativos.

## Ejercicio 1 - Cálculo de expresiones físicas/matemáticas
Calcula la fuerza peso, el número de vueltas dado un tiempo y una frecuencia, y el área de un círculo, con el valor de PI 
obtenido mediante la serie de Leibniz en lugar de mediante el uso de la función Math.PI. Trabaja con casting entre int, float y double.

## Ejercicio 2 - Manipulación de cadenas
Procesa una cadena de texto con substring, replace y contains. Calcula su longitud, su caracter central y comprueba si termina en
consonante usando operadores ternarios.

## Cómo ejecutar
Desde la carpeta `src/`:
```bash
javac tarea1/Ejercicio1.java
java tarea1.Ejercicio1
```

## Tecnologías utilizadas
- Java
- Entrada por consola (Scanner)
